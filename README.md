# Image Tagger

A small web app that detects objects in an uploaded photo and shows them as tags.
Built with python,streamlit and YOLOv8.


# What is YOLO?

YOLO stands for "You Only Look Once". It looks at the whole image in a single
pass and predicts what objects are present and where, which makes it fast.
The model used here is trained on the COCO dataset, so it can recognise
80 everyday object types (person, car, dog, chair, laptop, etc.).
